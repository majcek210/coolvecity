### coolvecity
Coolvecity is an open source discord bot planing to be a free alternative to mee6.
# Currently the bot has following systems:
 - welcoming system (has 3 subcommands to set the welcome channel, welcome toggle and welcome msg)
 - warn and ban system (can be used with /warn subcommand, /ban ,/unban)
The project will be developed with my framework called mjx-client that wraps discord.js and uses file routing to make managing command easier.
The project uses typescript. That decision was mostly made beacause I know a bit of javascript but i still prefer some type safety.
